# Автоматический новостной Telegram-канал

Бот собирает новости из RSS, склеивает дубли, пишет пост через нейросеть (OpenRouter по умолчанию, Gemini по желанию), проверяет факты вторым проходом и публикует в канал. Работает на GitHub Actions бесплатно.

## Запуск
1. **Бот**: в Telegram напишите @BotFather, команда /newbot, сохраните токен.
2. **Канал**: создайте канал, добавьте бота администратором с правом публикации.
3. **Нейросеть (OpenRouter)**: зарегистрируйтесь на https://openrouter.ai (можно через GitHub или Google), Keys → Create Key. Карта не нужна. Бесплатные модели имеют суффикс `:free`.
   Вариант Gemini: ключ на https://aistudio.google.com/apikey и переменная LLM_PROVIDER=gemini.
4. **GitHub**: создайте репозиторий (публичный: минуты Actions безлимитны), загрузите все файлы проекта, включая папку .github.
5. Settings → Secrets and variables → Actions → Secrets:
   - TG_BOT_TOKEN: токен бота
   - TG_CHANNEL: @username канала
   - OPENROUTER_API_KEY: ключ OpenRouter (или GEMINI_API_KEY для Gemini)
   - TG_ADMIN_ID: (необязательно) ваш числовой Telegram ID для уведомлений об ошибках
6. Вкладка Actions → news-bot → Run workflow. Дальше бот сам запускается каждые 30 минут.

## Управление
- **Пауза**: Settings → Variables → создайте PAUSED = 1 (или отключите workflow).
- **Провайдер**: переменная LLM_PROVIDER (openrouter или gemini).
- **Модели OpenRouter**: переменная OPENROUTER_MODELS, список через запятую (до 3, бот пробует по очереди). Бесплатные модели иногда пропадают: актуальный список на openrouter.ai/models?q=free.
- **Дневной лимит**: DAILY_LIMIT. Без пополнения счёта OpenRouter даёт 50 запросов в сутки на бесплатные модели, бот по умолчанию тратит не больше 45 (это около 22 постов в день: на каждый нужно 2 запроса). После разового пополнения от $10 лимит на бесплатные модели растёт до 1000 в сутки.
- **Источники и стоп-слова**: config.py.
- **Частота и объём**: cron в .github/workflows/news.yml; MAX_POSTS_PER_RUN, MAX_AGE_HOURS, MIN_SOURCES (переменные окружения, см. main.py).
- **Тест без публикации** (локально): DRY_RUN=1 python main.py

## Заметки
- Часть российских сайтов может блокировать зарубежные IP серверов GitHub. Такие ленты бот пропускает и пишет [warn] в логе (вкладка Actions).
- Лимиты и условия бесплатного тарифа Gemini меняются, проверяйте в AI Studio.
